# GABA 근거 인덱스 목표 계약

## 목적

GABA 섭취와 관련된 임상시험, 동물시험, 종설, 규제 및 안전성 자료를 한 곳에서 검색하고 검토할 수 있는 공개 근거 인덱스를 운영한다. 사용자는 연구의 핵심 결과뿐 아니라 연구의 의미, 마케팅 활용 가능 범위, 한계와 원문을 함께 확인할 수 있어야 한다.

## Goal Contract

```yaml
goal_id: GL-GABA-INDEX-2026
owner: Cellpinda
outcome: 공개 근거 인덱스에서 GABA 관련 조사와 근거 검토를 종결할 수 있는 탐색·검증 경험 제공
success_metrics:
  - 공개 사이트에서 문헌과 규제자료를 검색할 수 있음
  - 각 레코드에 대상, 제형, 용량, 기간, 대조군, 결과, 안전성, 한계가 표시됨
  - 연구의 의미와 마케팅 활용 방안이 근거 수준에 맞게 구분됨
  - 원문·DOI·PMID 연결과 철회·정정 상태가 추적됨
  - 배포 전 데이터 품질 및 문구 안전성 검증이 통과됨
scope_in:
  - 경구 GABA 섭취 인체 연구
  - GABA 관련 동물시험과 기전 자료
  - 종설·철회·정정 자료
  - 국내외 규제·안전성 자료
scope_out:
  - 근거 없는 효능·질환 치료 주장
  - 개별 제품의 허가·표시 적합성 자동 판정
  - 개인정보·접근 토큰·내부 연결정보의 공개 저장
constraints:
  - 원문 확인 여부와 추출 완성도를 표시한다
  - 연구 결과와 규제 문서를 같은 의미로 취급하지 않는다
  - 마케팅 문구는 대상·용량·기간·제형·한계를 함께 검토한다
  - 운영 원본과 공개 릴리스의 역할을 분리한다
authority_profile: AP-EVIDENCE-REVIEW
stop_conditions:
  - 출처를 확인할 수 없음
  - GABA 직접 섭취 여부가 불명확함
  - 철회·정정 또는 중대한 데이터 충돌이 해결되지 않음
  - 문구가 의료적 오인 또는 과장 광고를 만들 가능성이 있음
reporting_policy: exception_and_milestone
```

## 완료 정의

이 목표의 진척은 작업 파일 수가 아니라 다음 완료 술어로 판정한다.

1. 검색 가능한 공개 배포물이 존재한다.
2. 각 레코드에 출처와 검토 상태가 연결되어 있다.
3. 인체·동물·규제·안전성 자료가 분리되어 있다.
4. 연구의 의미와 마케팅 활용 방안이 결과와 한계를 넘어서지 않는다.
5. 데이터 품질 검증과 배포 검증이 통과한다.

진척률을 표시할 때는 완료율과 함께 근거의 최신 확인일, 추출 완성도, 원문 연결 여부를 별도로 표시한다.

## 대표 승인 영역

공개 사이트의 일반적인 코드·문구 수정은 검증 후 진행할 수 있다. 다음은 대표 확인 없이는 확정하지 않는다.

- 규제 적합성 또는 국내 표시 가능성에 대한 최종 판단
- 특정 제품에 적용하는 효능·안전성 마케팅 문구
- 외부 시스템에 쓰기 작업을 수행하는 연결
- 공개 범위를 바꾸는 데이터 추가 또는 삭제
